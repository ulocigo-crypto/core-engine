# Core Engine

## Description
### Overview

Core Engine is a high-performance, open-source game engine designed for developing 2D and 3D video games. It provides a comprehensive set of tools and features to create engaging, immersive gaming experiences.

### Features

* **Multi-platform support**: Run your game on Windows, macOS, Linux, and mobile devices.
* **Physics engine**: Leverage our built-in physics engine to create realistic simulations and interactions.
* **Graphics rendering**: Utilize our advanced graphics rendering capabilities for stunning visuals.
* **Animation system**: Create smooth, fluid animations with our built-in animation system.
* **Scripting**: Write custom scripts using our Lua and C# APIs.
* **Scene editor**: Visualize and edit your game world with our intuitive scene editor.

## Technologies Used

* **Programming languages**: C++, JavaScript, Lua, C#
* **Game engines**: DirectX, OpenGL, Vulkan
* **Build tools**: CMake, Make
* **Dependency management**: Conan

## Installation

### Prerequisites

* **C++ compiler**: GCC or Clang (version 10 or later)
* **Graphics drivers**: Install the latest graphics drivers for your system
* **Conan**: Install Conan using pip (`pip install conan`)

### Installation Steps

1. Clone the repository: `git clone https://github.com/core-engine/core-engine.git`
2. Install dependencies: `conan install .`
3. Build the engine: `cmake . && make`
4. Run the example game: `./core-engine`

### Build Configuration

To customize the build process, create a `build` directory and add a `CMakeLists.txt` file. Configure the build settings as needed.
